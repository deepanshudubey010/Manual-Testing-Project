## 1. Project Overview
**Project Name:** E-commerce Website Testing  
**Testing Type:** Manual Testing  
**Application:** Sample E-commerce Website  
**Objective:** To verify that the main features of an e-commerce website work as expected.

## 2. Test Scenarios

| Scenario ID | Test Scenario | Expected Result |
|---|---|---|
| TS_01 | Verify login with valid credentials | User should log in successfully |
| TS_02 | Verify login with invalid credentials | An appropriate error message should appear |
| TS_03 | Verify login with empty fields | Validation messages should appear |
| TS_04 | Verify Forgot Password functionality | The password recovery process should start |
| TS_05 | Verify product search functionality | Relevant products should be displayed |
| TS_06 | Verify product details | Correct product information should be displayed |
| TS_07 | Verify adding a product to the cart | Selected product should be added to the cart |
| TS_08 | Verify removing a product from the cart | Selected product should be removed |
| TS_09 | Verify updating product quantity | Cart quantity and total price should update correctly |
| TS_10 | Verify checkout functionality | User should be able to proceed to checkout |

## 3. Testing Status
Project status: In Progress
