# Manual Testing Project

## Project Overview
This is a beginner-level Manual Testing project created to practice software testing concepts using the SauceDemo e-commerce website.

## Application Under Test
- Website: https://www.saucedemo.com/
- Testing Type: Manual Testing
- Testing Area: Login, Products, Shopping Cart

## Project Documents
1. Test Scenarios
2. Login Test Cases
3. Product and Cart Test Cases
4. Bug Reports
5. Test Execution Report

## Testing Activities
- Verified login with valid credentials.
- Tested invalid password and empty input fields.
- Checked the locked user scenario.
- Verified product details displayed on the page.
- Tested adding and removing products from the cart.
- Compared product prices on the Products and Cart pages.

## Tools Used
- GitHub
- Browser
- Manual Testing

## Project Status
Basic functional testing has been performed. Some test cases remain unexecuted.

This is a practice project created for learning and portfolio purposes.
